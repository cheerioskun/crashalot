Updated October 24, 2026. These are candidate views and a proposed sequence, not accepted factual claims or permission to invent missing evidence.

**The user has now authorized the first presentation page and question-led placeholders**. Continue theme and component review in `components.html`. No final theme is chosen. Use existing project datasets only, with ad hoc inspection rather than new bespoke scripts.

Draft 1 still targets an agreed first graph set and flow, a landing page with question-led placeholders, and one fully implemented, polished visualization. D3 owns charts; Reveal.js hosts independently structured views.

The first source-backed chart is a component specimen before it becomes a presentation page. Counts and rates are valid; the rate complement must not be labelled an exact observed safe-flight percentage. See [source audit](safety-trend-source.md).

Every view must add understanding. Drop the lower-priority flight-phase view if it interrupts the main argument or overcrowds draft 1. Placeholders state the intended question and missing evidence, without fabricated graph shapes. No interaction, palette, or visual metaphor should conceal the scope or change what the data means.
