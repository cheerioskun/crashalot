Four colors reserved for data

Neutral and interface roles

Text, surfaces, reference marks, and controls support the evidence. Their colors are independent of the data palette.

SurfaceThe page beneath the story

A theme may change surfaces, type treatment, and colors. It does not change the data, the scales, or what a mark means.

These are library themes to compare, not a finished visual identity. All three use local assets and the same system typeface.
